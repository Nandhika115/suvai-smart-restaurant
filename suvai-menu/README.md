# Suvai Restaurant Menu

Welcome to the Suvai Restaurant Menu project! This web application allows users to browse a delicious menu, place orders, and manage their cart seamlessly. Below are the details regarding the project setup, features, and usage.

## Project Structure

The project is organized as follows:

```
suvai-menu
├── index.html          # Main HTML document for the web page
├── src
│   ├── css
│   │   └── styles.css  # CSS styles for the warm dark theme and layout
│   ├── js
│   │   ├── app.js      # Main JavaScript logic for dynamic menu interactions
│   │   └── cart.js     # Cart functionality for managing orders
│   └── data
│       └── menu.js     # Menu items data
├── package.json        # Project configuration and dependencies
├── .gitignore          # Files and directories to ignore in version control
└── README.md           # Project documentation
```

## Features

- **Responsive Design**: The menu is fully responsive, ensuring a great user experience on both desktop and mobile devices.
- **Warm Dark Theme**: The application features a warm dark theme that enhances readability and visual appeal.
- **Dynamic Menu**: Users can filter and sort menu items based on their preferences.
- **Cart Functionality**: Users can add items to their cart, update quantities, and view their total order cost without any backend integration.
- **Interactive UI**: The application provides a smooth and interactive user interface for a delightful ordering experience.

## Setup Instructions

To get started with the Suvai Restaurant Menu project, follow these steps:

1. **Clone the Repository**:
   ```bash
   git clone <repository-url>
   cd suvai-menu
   ```

2. **Install Dependencies** (if any):
   ```bash
   npm install
   ```

3. **Open the Project**:
   Open `index.html` in your web browser to view the application.

## Usage

- Browse through the menu items displayed on the main page.
- Use the filtering and sorting options to find your desired dishes.
- Click on the "Add to Cart" button to add items to your cart.
- View and manage your cart by clicking on the cart icon.
